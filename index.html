FAQ

Sebelum masuk.

Kapan server bisa dimasuki?

Alamat dan jadwal server akan diumumkan saat proyek siap untuk di-launch secara resmi.

Apakah Java dan Bedrock didukung?

Target dukungan Java dan Bedrock tetap dibahas sesuai kebutuhan komunitas, dan belum dipublikasikan sebagai daftar resmi.

Apakah toko rank sudah bisa digunakan?

Belum. Website ini menampilkan informasi visual dan daftar rank, bukan proses pembayaran atau login.
