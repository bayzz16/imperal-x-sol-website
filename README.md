# Imperal Network × Slice of Life

Static landing page for the Imperal Network × Slice of Life Minecraft project. Built with HTML, CSS, and small vanilla JavaScript so it can be hosted free on GitHub Pages.

## Publish for free

1. Open the repository on GitHub.
2. Go to Settings → Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Choose branch main and folder /(root), then save.
5. Wait for the Pages deployment to finish. GitHub will show the public URL in Settings → Pages. For this repository, the expected project URL format is https://bayzz16.github.io/imperal-x-sol-website/, but it is not live until Pages is enabled successfully.

GitHub's official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Current scope

This is a static public landing page. It does not implement Discord login, Minecraft account linking, a database, checkout, payment processing, admin tools, or in-game rank delivery. Do not collect passwords or payments through this site.

The server address, official Discord invite, final rank names, benefits, and prices are intentionally omitted until the project owner confirms them.

## Files

- index.html: page structure and content.
- styles.css: responsive visual design and reduced-motion handling.
- script.js: accessible mobile navigation.
- DESIGN.md: visual direction and motion rationale.
- .nojekyll: asks GitHub Pages to serve the static files without Jekyll processing.

## Local checks

No build step or dependencies are required. Check the HTML, CSS, and JavaScript in a browser at desktop and mobile widths before treating the page as production-ready. The GitHub Pages deployment itself must still be confirmed in repository Settings.
