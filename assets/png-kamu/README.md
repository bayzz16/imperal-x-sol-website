# Folder PNG dari Bayu

Letakkan PNG yang ingin dipakai untuk website di folder ini, atau gunakan subfolder yang sesuai di bawah. Setelah file diunggah ke GitHub, aku bisa membaca file dari repository dan mengedit website tanpa kamu mengirim ulang gambarnya lewat chat.

- `logo/` — logo Imperial SMP dan SoL asli.
- `rank/` — PNG badge rank, idealnya satu file per rank.
- `lobby/` — screenshot/foto lobby Minecraft yang boleh dipakai sebagai visual website.

**Penting:** unggah file gambar asli `.png`, bukan screenshot preview GitHub. Jangan unggah password, token, atau data pribadi.
